# 17~24岁  长沙读书 （11年到18年）

彼时的毛文章极为张狂，认为中国一切的改变，无论一会、宪法、总统、内阁……都是舍本逐末，没有从本源做起来。
说今人如袁世凯、孙文、康有为三人，前两个不用提了。只有康有为知道改变中国问题的根本在哪里，不过仔细看他的文章，很华丽
但经不住推敲，都是一些空话。

    黎锦熙信全文

    今之论人者，称袁世凯、孙文、康有为〔4〕而三。孙、袁吾不论，独康似略有本源矣。然细观之，其本源究不能指其实在何处，
    徒为华言炫听，并无一干竖立、枝叶扶疏之妙。

    今日变法，俱从枝节入手，如议会、宪法、总统、内阁、军事、实业、教育，一切皆枝节也。
    枝节亦不可少，惟此等枝节，必有本源。本源未得，则此等枝节为赘疣，为不贯气，为支离灭裂，
    幸则与本源略近，不幸则背道而驰。。

    夫本源者，宇宙之真理。天下之生民，各为宇宙之一体，即宇宙之真理，各具于人人之心中，虽有偏全之不同，
    而总有几分之存在。今吾以大本大源为号召，天下之心其有不动者乎？ 

    天下之心皆动，天下之事有不能为者乎？ 
    天下之事可为，国家有不富强幸福者乎？ 

彼时，梁启超写《新民说》，《少年中国说》认为救国之根本是塑造新民，苟有新民，则必有新国。
毛遂呼朋唤友、结交同志、建立了新民学会，如何叔衡、蔡和森……

可是，同志已经聚集、问题已经明确，可是他还没有找到如何解救中国的办法。

    13年/19岁毛休学半年，在湖南图书馆闭门读书，《原富》《物种起源》社会契约论》《论法的精神》《天演论》，
    之后认识杨昌济
    杨要求毛
        贯通古今、融合中西
        鼓励质疑而不要被动接受

# 24~27岁（18年~21年） 北京

毛泽东曾用一句话精准描述1918年的自己："自由主义、民主改良主义、空想社会主义等思想的大杂烩。
其之前在岳麓山搞过“新村”实验（无政府主义社区，失败了————"那时我们好几个人，住在一个房子里，每天吃的是蚕豆拌饭。"
现实把这个乌托邦碾得粉碎）————毛遂认识到不要轻易相信那些美好但不切实际的主张。

在北京，毛在李大钊和陈独秀的影响下，读了《共产党宣言》《阶级争斗》《社会主义史》。

毛遂很快接受了马克思主义。这种很快的接受并不是美好而不切实际的。

这期间，他参与了政治实践

    驱张运动（驱逐湖南军阀张敬尧）：他首次独立领导大规模政治运动，在北京、上海之间奔走请愿，
        接触各派政治力量
    湖南自治运动失败：他试图走温和改良的路，搞"湖南共和国"，结果被现实打得粉碎。他在给向警
        予的信中写道："政治改良一途，绝无希望"

毛遂彻底抛弃了对梁和唯心主义思想的信仰，改信马克思主义。

    "我一旦接受了马克思主义是对历史的正确解释以后，我对马克思主义的信仰就没有动摇过。

共产主义早期（马恩），也是一种极为美好而唯心的理论，但经过列宁改良之后就完全不同了，理想化的理论变得极为
强大、具备社会可操作性的社会改造实践。————它不但在俄罗斯这个羸弱的国家建立了一个新的乌托邦、而且在内部
白军反叛、欧洲诸强的干涉中、建立起来这个乌托邦—…………这国家情形极类似中国，也极鼓舞中国、中国人
看到了道路和方向。

    萧子升是毛泽东青年时期最亲密的挚友，两人同窗共读，1917年一起"游学"五县，1918年共同创立
    新民学会。他们是灵魂上的知己。
    
    但1919年萧子升赴法留学后，接受了改良主义和无政府主义，主张以教育为工具的渐进变革。毛泽东
    则在湖南自治运动失败后彻底转向暴力革命。
    
    1921年3月萧子升回国，两人彻夜长谈，激烈争论。萧回忆："毛泽东一直劝说我加入共产党……只要30
    年至40年，共产党就能改变中国。"但萧坚信教育改良，说宁愿"等1000年"也不参加流血革命。

    1921年7月，两人同船从长沙出发。他们同床而眠，争论直到凌晨。船到武汉，萧子升下船。毛泽东继续前
    行——去上海参加中共一大。

    此番分手，地老天荒，不复相见。
    此后萧子升投入国民党阵营，大陆解放后流亡法国、瑞士、乌拉圭，1976年客死异乡。遗愿是骨灰运回湖南湘乡。

    这件事在毛泽东个人史上极为重要：它说明他为信仰付出的代价不仅是敌人的子弹，还有友谊的永久丧失。
    他不是冷血无情地选择革命——他选择时，放弃了青年时代最亲密的朋友。

# 27~41岁（1921—1935）

    "我这个菩萨，过去还灵，后头就不灵了。他们把我这个木菩萨浸到粪坑里，再拿出来，搞得臭得很。
    那时候，不但一个人也不上门，连一个鬼也不上门。"
这不是修辞——是真的无人登门。他曾在担架上跟着长征队伍，疟疾发作，几乎丧命。此时指挥权在博古、
李德手中，红军一路惨败，湘江一战八万锐减至三万。
痛苦是如何转化为思想的？
毛泽东后来总结这段经历时说了一句意味深长的话："一个人没有受过十年八年委屈，就是教育没有受够。
他在这个极端孤立的时期做了什么？他读书、思考、找个别能说话的人探讨。**他要搞清楚的问题已经不是
"怎么打仗"，而是更深层的：为什么一个正确的路线会被错误地抛弃？问题出在哪里？**

1935年遵义会议确立了毛泽东的实际领导地位。此后一个显著的变化引起了身边人的注意。

贺子珍回忆："毛泽东在遵义会议以后，有很大的变化，**他更加沉着、练达，思想更加缜密、周到，特别是更善于团结人了。**"

他自己感慨："办什么事都要有个大多数啊！"

此前毛泽东的毛病是独断、急躁、火气大。（看看他之前学生时代的张扬和文章就大概清楚了）

    此前的毛，是青年，此后的毛，是中年。
    青年的毛，挥斥方遒、指点江山、得了道，拿定了主义；
        莫斯科的路线和自己不合、就不采纳莫斯科的意见。
        别人和自己意见不合、就激烈要求别人接受自己意见
    就连老好人朱德也对他不满说：
        你在前委，就要求军队听前委的，说没有调查，就没有发言权。
        你在党委，就要求军队听党委的，说要党指挥枪。
        合着，你在哪，就听哪。你这是好权，不民主。
    ……

    遵义会议打鼓新场一仗，毛依然是意见和大多数人相左、情绪激动，大家不同意还辞职威胁撂了挑子。
    
    不过，不知为何，毛半夜挑灯找周恩来反复陈述厉害。

    此夜之后，周围人说据说性情大变，变得更懂得收敛锋芒，团结同志。

# 41~54岁（35~48岁） 延安

毛，地位绝对稳固。
理论总结《实践论》《矛盾论》，并以此来指导了中国革命。

很特殊的是 整风运动：用自己的思想统一全党

    "惩前毖后，治病救人"——这个方针的形成，也和他个人的"团结—批评—团结"的心路历程有关。
    他自己就是从被排挤到被接纳的经验中体会到：批判的目的是团结，不是消灭。

**团结—批评—团结**

# 49年后~~~孤独的晚年
 
1965年6月26日，毛泽东在听取卫生部部长钱信忠汇报后，发出了著名的**"六二六指示"**，其中最为人传诵、也最刺痛体制的一句话是：

    "卫生部是城市老爷卫生部！"
 
66年，毛发动了文革

    
讨论文革之前，我们要思考几个问题
    
    1，是否中国历史必然是个周期律
    2，是否中国历史必然是穷人造反、翻身、做了统治阶级、然后又一波穷人造反……
    3，靠肉体消灭可以消灭么？可以改变么？
    
这些问题，都和毛的一生有关。

    他相信社会的一切问题、一切力量都来源于心。而不在于具体的制度、形式。
    他不相信肉体的消灭能改变什么。
    他相信批评、经历、现实、经历、实践……对心的改造，也相信心对前者的改造。

晚年，面对自己的失败，他并没有彻底的消灭一切潜在对手、反而可以的保存他们
    
    天要下雨，娘要嫁人、随他去吧

这，也和他的根本哲学有关。晚年的他，极为孤独，一反年轻时豪迈乐观的性格。很容易触景生情。
    
    观看解放战争入城历史纪录片触景怀旧失声大哭

也曾品读诗词，读到一水横陈，连岗三面，做出争雄势。六朝何事，只成门户私计时触景感伤、哽咽落泪

此树婆娑，生意尽矣…… 昔年种柳，依依汉南；今看摇落，凄怆江潭。树犹如此，人何以堪！
