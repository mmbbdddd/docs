# AI的思考

最近负责智能研发平台的设计和调研，有些想法。

Agent产品就两条路。ClaudeCode，提示词完了人几乎消失。Cursor，人一步一引导，AI只是辅助。从辩证角度看，后者应该更好。但实际CC压倒性流行。

为什么？翻它代码，除了一层AgentLoop，几乎什么都没有。消息交互、上下文、模型调度、记忆、工具、MCP、技能、输出转换、校验、护栏、容错、权限——全是工程件，跟智能没关系。

它赢在哲学：**相信AI，帮助AI。**

想想也对。AI蒸馏了人类几乎所有知识。竞赛数学满分，专业领域超博士，下棋超人类顶尖60%，百年数学难题被攻克。能力上，没理由不信。

帮它，是因为它还有缺陷：token限制、注意力稀释、发散、私域知识缺失、沉淀经验缺失、只能看不能动手。但这些要么已解决，要么迟早解决。

那困住AI的，除了计算机这个盒子，还有什么？具身智能和机器人也在发展。**人，以后的价值在哪？**

做codebase技术调研那次，才发现它真正的短板。

搜codebase方案，几十个东西，琳琅满目——codebase-ai、codegraph、RAG、LSP、Monorepo……很多不知道干嘛的。指挥它深度调研所有技术，做评价表格。结果一看就知道不对——很多技术不是一个层次，没法放一起打分。有些同层次的，不同场景优劣完全不同，单单比较性能指标没意义。

比如向量数据库，文本少的时候准确性不如Agent，大量文本确实强。但如果场景是Agent嵌入式CLI呢？没法孤立地比。

于是回头分析这些编辑器产品的范式，以及我们自己Agent平台的范式。大概四类：

- 传统编译器：PSI、AST、LSP建符号表，做结构化导航
- AgentFirst编辑器：ClaudeCode，没有CodeBase，纯ripgrep+LLM多轮推理
- Agent辅助编辑器：Cursor，LSP做代码图谱，TreeSitter给Agent做图谱
- 云代码平台：GitHub、Sourcegraph，向量库+TreeSitter图导航，解决海量搜索

技术上也四类：grep关键词、结构化导航（AST/符号表）、向量语义导航（检索+召回+重排）、大模型多轮检索推理。

终于把乱的东西结构化，和业务场景关联起来了。

但过程里最难受的是：让AI结构化、体系化、归纳知识的时候，不管怎么提示，从产品模式到技术范式到检索模式到存储模式——产出质量很差，基本在应付。不能像大多数问题那样准确归纳。

我问它：你是不是只能表层语义推理，无法深入归纳底层规律？

它说：能从已有知识提炼总结，不擅长从零原创发现颠覆性规律。复杂深度归纳容易逻辑幻觉、片面总结。

基本可以确定了。**私域的业务模型抽象、架构范式，它很难。通用技术架构，它很胜任。**

毕竟，就是个已有知识分布的概率预测工具。短期内，在没见过领域的知识归纳、抽象，还到不了人。无法把知识反刍成哲学、原则，再根据哲学和原则泛化。

- 替代信息搜集，替代不了实地调研
- 替代分析师，替代不了业务洞察
- 替代技术架构师，替代不了领域架构师
- 替代程序员，替代不了风险判断

在新一代研发平台里，核心抽象叫HITL——Agent+人+某类任务的接口。

可以有各种实现。没人的，干不要求质量的工作。单Agent强模型+多人的，做设计。多Agent+人的，做开发。多Agent串行不复用上下文，做高隔离验证。多Agent并行共享上下文，做信息共享。只有搜索和MCP的，做推理。有工具但无Web和MCP的，干高一致性输出。

HITL配置即HR，即雇员。暂时有质量要求的还离不开人。

宏观上编排HITL完成需求→设计→编码→测试→发布。最简单的pipeline，严谨可控。

但整体上，我们不完全信任vibe coding。它能力太强，容易发散，引入太多复杂性。快速迭代到后期不可维护。极端复杂业务场景的领域抽象它没有。能提速，无法简化。自行车提速到汽车是危险的。

宏观上人主导架构和拆分，Agent辅助。拆到基本单元后（复杂度接近CRUD），Agent主导小功能组件开发。每个单元人兜底。

架构范式在演：Prompt工程 → Context工程 → Harness工程 → Loop引擎。

从Harness到Loop，本质是用不靠谱的组件搭高可靠系统。再往下没有理论指导了。数学、量子力学、软件都指向不确定性和混沌。复杂系统科学还没有奠基性突破。

从生物演化看，唯一明确的路：复杂系统有统一、简洁优雅又高度复杂的原子结构。[领域驱动战术设计](领域驱动战术设计.md)

和去年比，我对AI的看法变了很多。需要持续跟。

《人月神话》论定软件的本质是概念×关系×变化造成的指数复杂度。根本解法是抽象——最少概念，最少关系，最少变化。

但AI只是个效率工具，不是抽象工具。编码效率提了好几倍，整体软件工程效率没提升。很奇怪。

也许Cursor的路子才是对的。ClaudeCode隐患很大，不是长久路子。但它的进展，确实探到了AI能力的极致边界。
